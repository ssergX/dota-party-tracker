## ⚡ TL;DR

Добавляешь бота в чат пати, регистрируешь аккаунты (`/add`), играете — бот ведёт **общий лидерборд**: оценка MMR, серии, винрейт, KDA, награды, совместные игры и подробные карточки по каждому. Раз в день присылает дайджест.

## ⚠️ Честно про MMR

Точного числа MMR в Dota 2 **нет ни в одном публичном API** — Valve закрыл выдачу ~2019. Поэтому MMR **оценивается**:

```
текущий MMR ≈ стартовый MMR + (победы − поражения) × шаг      (шаг по умолчанию 25)
```

Стартовый MMR вводишь ты (при `/add` или через `/setmmr`), а бот считает игры и оценивает изменение — везде помечено значком `≈`. **Медаль/ранг, число игр, KDA, винрейт, герои, GPM — реальные данные.**

> 📌 OpenDota видит матчи игрока, только если у него в Dota 2 включены **«Открытые данные матчей»** (Настройки → Опции → Дополнительно). Иначе — 0 игр.

## ✨ Возможности

### 🏆 Лидерборд (`/stats`)
- Оценка текущего MMR с трендом 📈/📉 и медалью-эмодзи по рангу
- Серии побед/поражений 🔥/💧, игры, винрейт, KDA
- 🎖 **Награды пати:** 👑 Король винрейта · 🛠 Работяга · 🗡 Керри · 💀 Фидер

### 🤝 Совместная игра (`/together`)
- Сколько пати сыграла **вместе** и общий винрейт (по общим матчам)
- 👯 Лучшее дуо

### 🦸 Герои (`/heroes`)
- Топ-3 героя каждого участника + винрейт по герою

### 🎮 Карточка игрока (`/player <ник>`)
- GPM / XPM / ластхиты, средняя длительность игр
- 🧑‍🤝‍🧑 Соло vs пати · 🌙 винрейт по времени суток
- 📋 форма (последние 5 ✅/❌), 🌟 лучшая игра, макс. серия побед
- 🛣 винрейт по линиям (safe/mid/off) · 💠 распределение GPM

### 📅 Автоматизация
- Ежедневный дайджест в заданный час (once-per-day с догоном при простое)
- 🎮 Оповещения о новых играх (каждые ~4 мин; игроки одного матча — одним сообщением, с итогом «сегодня вместе») и о новых достижениях
- 📅 Недельная сводка по понедельникам: кто поднялся/просел, герой недели, лучшая серия, совместные игры
- 🔔 Оповещения о смене ника/аватарки в Steam
- 💾 Ежедневный бэкап БД в `<папка БД>/backups` (хранится `BACKUP_KEEP` копий, по умолчанию 7)
- ⚙️ Все оповещения включаются в `/settings`
- Работает в групповых чатах (у каждого — свой лидерборд)

## 🚀 Быстрый старт

Нужен Python 3.12+ и токен бота от [@BotFather](https://t.me/BotFather).

```bash
git clone https://github.com/ssergX/dota-party-tracker.git
cd dota-party-tracker

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt

cp .env.example .env        # и вставь BOT_TOKEN (STRATZ_API_KEY — по желанию: позиции/IMP)
python -m mmrbot
```

Бот работает по long-polling — держи процесс запущенным. Остановка — `Ctrl+C`.

### 🐳 Docker (для сервера)

```bash
docker compose up -d --build
docker compose logs -f
```

## 🎮 Команды

| Команда | Что делает |
|---|---|
| `/add <ссылка или ID> [Имя] [MMR]` | добавить аккаунт (Dotabuff / OpenDota / Stratz-ссылка, SteamID64 или account_id) |
| `/stats` | лидерборд + серии + награды пати |
| `/stats неделя` · `/stats месяц` | итоги за период: игры, победы–поражения, оценка MMR, KDA |
| `/today` | активность за последние сутки |
| `/together` | совместные игры пати, лучшее дуо |
| `/heroes [ник\|@тег] [день\|неделя\|месяц\|всё]` | топ героев участников / герои игрока за период |
| `/hero <герой> [период]` | кто из пати лучше играет на герое |
| `/match [id] [ник\|@тег]` | разбор матча: позиция, лейн, IMP, GPM/XPM, урон, пати (по умолчанию последний) |
| `/roles [ник\|@тег] [период]` | позиции 1–5 и винрейт на каждой |
| `/menu` | меню с кнопками |
| `/player <ник>` | подробная карточка игрока |
| `/steam <ник>` | аватарка и текущий ник из Steam-профиля, ссылка, SteamID, ранг, Dota Plus |
| `/graph [день\|неделя\|месяц\|всё]` | график динамики оценки MMR по игрокам |
| `/achievements [ник]` | достижения (серии, число игр, игры на герое, рекорды) и антирекорды |
| `/settings` | шаг MMR, час сводки, часовой пояс, оповещения |
| `/list` · `/remove <ник>` | список / удаление игроков |
| `/setmmr <ник> <MMR>` | задать/поправить MMR |
| `/setstep <шаг>` · `/settime <час>` | шаг оценки MMR / час дайджеста (МСК) |
| `/help` | справка |

> `/add` принимает любую ссылку — из неё берётся только числовой `account_id`. Реальные данные тянутся из OpenDota API.

## 🧱 Стек и структура

**Python 3.12 · aiogram 3 · SQLite · APScheduler · requests → OpenDota API** (без ключа).

```
mmrbot/
├── ids.py          разбор ссылок/ID → account_id
├── ranks.py        rank_tier → медаль (+ эмодзи)
├── stats.py        чистые расчёты: win/loss, KDA, серии, оценка MMR…
├── heroes.py       справочник героев (из OpenDota)
├── party.py        совместная игра пати, лучшее дуо
├── achievements.py правила достижений и антирекордов (чистые функции)
├── charts.py       график MMR (matplotlib → PNG)
├── backup.py       ежедневный бэкап SQLite
├── opendota.py     клиент OpenDota (троттлинг, ретраи, refresh)
├── stratz.py       клиент Stratz GraphQL (позиция/роль/лейн/IMP по матчам)
├── keyboards.py    inline-меню и кнопки периодов
├── storage.py      SQLite (чаты, игроки, кэш матчей)
├── tracker.py      оркестровка: обновление игроков, сводки, награды
├── formatting.py   рендер сообщений (карточки, HTML)
├── bot.py          хендлеры команд aiogram
├── scheduler.py    ежедневный дайджест
└── __main__.py     точка входа (python -m mmrbot)
```
